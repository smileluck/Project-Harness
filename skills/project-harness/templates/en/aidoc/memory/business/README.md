# Business Requirement Memory

Stores one record per business requirement raised by the user. The requirement index is maintained solely in [../project-memory.md](../project-memory.md); this file does not duplicate it.

## Rules

- When the user raises a business requirement, add or update one record.
- Use `TEMPLATE.md` as the template for new records.
- After recording, update the index in `../project-memory.md`.
